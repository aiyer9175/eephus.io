# 14 — Naming Ruling

**Selected: `Advancement Pace+`** (charter primary recommendation, confirmed).

| criterion | how the name meets it |
|---|---|
| observed advancement | "Advancement" names the thing measured — levels actually attained |
| peer adjustment | the "+" suffix is the house convention for peer/context-adjusted 100-scale stats (Park+, Defense+, Contact+) |
| descriptive status | "Pace" describes motion already made; no future tense |
| no causal/predictive claim | contains no skill, talent, value, or projection vocabulary |

## Alternatives assessed
- `Progression Pace+` — acceptable; "progression" slightly implies internal development
  (skill growth) rather than ladder movement. Runner-up.
- `Minor-League Pace+` — ambiguous (pace of play?); weakest.
- `Level Advancement+` — accurate but reads as a count, not a rate; drops the time axis.

## Rejected on scientific-accuracy grounds (charter list, affirmed)
- `Development Velocity` — collides with the *predictive* timing lever in the PD
  integration work (the strongest single reason: same words, opposite epistemic status);
  also implies skill development.
- `Development+` / `Growth Rate` — imply measured skill growth; this metric never
  observes skill, only placement.
- `Readiness Pace` — "readiness" is a reserved predictive concept (separated field in
  the challenger architecture).
- `Promotion Talent` — flatly claims an ability; promotion decisions belong to
  organizations, not player talent alone.

## Comprehension note for glossary copy
The name must always ship with the one-line gloss ("how quickly a player has moved
through the minor-league ladder relative to comparable peers — not a talent grade or
projection"), because "+" stats elsewhere on the site (e.g. wRC+-style) invite a
percentage reading that this standardized-residual scale does not support.
