How to embed the Prospect Tracker

Three ways to get the tracker onto your site, ordered from simplest to most flexible.

Option 1: Iframe (zero setup)

Host index.html and data/timeseries.json anywhere static (Netlify, GitHub Pages, S3, your own server), then embed via iframe. The tracker is fully self-contained.

<iframe
  src="https://your-host.example.com/prospect-tracker/index.html"
  width="100%"
  height="900"
  style="border: none;"
  title="MLB Prospect Stock Tracker">
</iframe>

Option 2: Same-domain include

If you want the tracker on your existing site without an iframe (e.g., to share fonts, header, footer), copy the web/ directory to your site and link to index.html like any normal page. The styles are scoped enough not to bleed into your site's CSS, but you may want to wrap the <style> block contents in a parent selector if you do see conflicts.

Option 3: Custom JSON host

If you want to host timeseries.json separately from the HTML (e.g., put the JSON on a CDN while the HTML stays on your main site), edit the DATA_URL constant near the bottom of index.html:

// Change this line near the bottom of index.html:
const DATA_URL = "https://cdn.your-host.example.com/timeseries.json";
CORS note: if timeseries.json is hosted on a different origin than the HTML, the JSON host must send Access-Control-Allow-Origin: * (or your specific domain). Most static hosts let you configure this; GitHub Pages and Netlify enable it by default for cross-origin reads of public files.

Refreshing the data

Every month, run python run_monthly.py on the source machine (or schedule it via cron / GitHub Actions). The resulting data/timeseries.json is what the page reads. As long as you re-upload that file, the embedded tracker updates with no other changes needed.

See web/README.md for full deployment recipes (Netlify, GitHub Pages, S3, plain Nginx).
