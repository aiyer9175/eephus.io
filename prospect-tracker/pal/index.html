Alchemy Lab β beta

Players in the wrong job. Which relievers profile as starters and which starters would shine in relief, which hitters are worth more runs at a different position, plus the history of the conversions that worked and the ones that did not. The backtest grades each lane on its own: the starter-to-relief signal is validated, the reliever-to-starter list is a structural screen, and the position-conversion matrix is validated for the SIZE of a move but not for guessing which players clubs actually move.
