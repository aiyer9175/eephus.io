# Runbook 2026-08-03: what the box owes, and what was verified locally

Three commits land on `main`: the eFV regen-tail P0, rest-of-season control
pricing, and the Top-100 GFX chip layout. Code and tests are green
(2,846 passed). The served data artifacts are NOT in these commits, because the
three that matter here are gitignored by design and the box is the single
writer. This is the list of what has to run there.

## What must run on the box, in this order

```
1. run_monthly.py                       # normal nightly/monthly chain
2. python efv_export.py                 # the nightly does NOT call it
3. run_monthly.py --rebuild-only        # second pass, so every artifact agrees
```

Step 2 is not optional. The nightly monthly chain does not run `efv_export`, so
`data/xfv.json` stays behind the freshly scored matrices unless it is run by
hand; that gap is exactly what hid the regen-tail crash for two days.

Semantic change to `mlb_projections.json` this cycle (`surRos` / `surTotal`),
so the two-pass rule applies: `rebuild_only` never calls `proj_export`, and the
trade export inside d9 reads the PRIOR night's projections file. One pass will
serve a trade board built on yesterday's projection semantics.

## Regen-order dependency introduced this cycle

`fa_export` now reads `mlb_projections.json` to correct a club attribution
(the FA availability page had A.J. Minter on MIN). `proj_export` already runs
before `fa_export` in both the monthly and daily chains, so nothing needs
reordering - but if that order ever changes, the FA board silently falls back
to the scraped club rather than failing, which is the intended degradation and
also the thing that will make the regression invisible. Noted here so a future
reorder is a decision rather than an accident.

## Registered, not fixed

* `_gradePrimary()` (prospx) returns `"xfv"` for ANY sort other than `"fv"`,
  so sorting the board by age or a Statcast index still labels badges, legend
  and surplus source as eFV-led. The fix is to stop overloading `state.sort`
  with the grade choice - `state.debutGrade` is the precedent - which changes
  grade selection site-wide and wants a browser to verify.
* Star-rental pricing. The prorated rest-of-season WAR runs through the same
  convex tier curve as a full season, which under-prices concentrated wins
  relative to how contenders actually bid at a deadline. Correcting it needs a
  measured premium, not a default.
* The 361 `no_contract` (mostly pre-arb) vets stay unpriced. Still the largest
  open value on the board, still a real model with a real gate.
