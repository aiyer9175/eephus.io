## M2 -- lambda re-selection confirmation (NO SHIP; one FLAGGED finding)

Lab: `tools/efv_lambda_confirm_lab.py` -> `data/xfv_lambda_confirm_eval.json`. Sweep
[0.45,0.80] step 0.0125, identical fold machinery to `rank_calibration`, composite =
pooled + within-tier + t45, bootstrap 1000 resamples.

- **PIT: clean confirmation.** Composite peaks INTERIOR at ~0.54-0.55; live 0.54 sits on the
  peak. Swept-best 0.525 composite 0.5705 vs live 0.5706 (delta -0.0001), bootstrap P 0.44.
  Live confirmed.
- **HIT: mechanically passes the 4 clauses but FLAGGED, not shipped.** Swept-best is the grid
  ceiling 0.80 (composite +0.0232 over live, pooled +0.0056, era no-drop, bootstrap P 0.973).
  BUT the wide diagnostic curve shows the hitter composite is **monotone increasing to the
  0.90 clamp with no interior optimum** -- all three components (pooled, within-tier, t45)
  rise the whole way. 0.80 is a **censored boundary maximizer, not an identified optimum**.

**Why not auto-shipped:** shipping 0.80 would raise the deliberately-registered
`rank_calibration` [0.50,0.70] robustness cap as an unvetted side effect of a confirmation
lab. That cap was set with its own adversarial bootstrap (which, on an earlier vintage, found
within-tier/fringe peaking ~0.65 -- the matrix regen invalidated that premise). An interior-
optimum guard was added to the lab (documented) so the no-ship is principled and visible.

**FLAG for owner (high priority):** on the current vintage the hitter blend wants lambda at
the ceiling; the 0.70 cap now leaves composite on the table. Re-litigate via a DEDICATED
pre-registered "raise the hitter lambda cap" experiment (confirm the monotonicity is stable
across fold years, verify the high-lambda pooled CI, pick a principled ceiling) -- do NOT ship
a boundary value. Full evidence in the artifact's `flagged_finding_hitter_lambda_cap`.

## M3 -- hierarchical shrunk per-cohort lambda (NO SHIP)

Lab: `tools/efv_cohort_lambda_hier_lab.py` -> `data/xfv_cohort_lambda_hier_eval.json`
(the binding E-LAMBDA artifact left untouched). `lambda_c = (n_c*lambdahat_c + k*lambda_global)
/(n_c + k)`, lambdahat forward-chained per-cohort argmax, k in {50,100,200} selected on
pre-2023 folds only.

Genuine advance over raw E-LAMBDA, but still fails the full gate:

| Clause | Result |
|--------|--------|
| c1 pooled no-decrease both sides | **PASS** (hit +0.0030, pit +0.0026 -- shrinkage FIXED E-LAMBDA's pit -0.0104) |
| c2 pit:ifa improves >= +0.01 | **PASS** (+0.0133 -- proven direction captured) |
| c3 no gated cohort degrades > 0.005 | **FAIL** (hit:ifa -0.0062) |
| c4 per-era no drop > 0.01 | **FAIL** (pit 2022-23 -0.0114) |
| c5 within-tier + t45 >= -0.005 | PASS |
| c6 fold stability (lambda_c range <= 0.20) | **FAIL** (hit:college, hit:ifa, pit:college, pit:ifa) |

The blocker is no longer pooled degradation (solved) but residual per-cohort instability on
25-160 row OOF pools plus hit:ifa / pit-late-era collateral. The pre-registered k selection
maximizes accuracy and lands on the lightest shrink (pit k=50); re-selecting k to pass
stability would be goalpost-moving, so it was not done. Keep-alive: wait for resolved 2024+
cohorts (more fold years shrink OOF variance); a pit:ifa-ONLY shrink is a narrower future
candidate needing its own gate. **No production code changed** (verdict != ship -> global
lambda retained).

## M4 -- ridge alpha grid + holdout criterion (NO SHIP)

Lab: `tools/efv_alpha_criterion_lab.py` -> `data/xfv_alpha_criterion_eval.json`. Baseline
reproduces the shipped ridge exactly (hit 0.3523, pit 0.2757). Treatment = grid
(0.3,1,3,10,30,100,300) + max-weighted-Spearman holdout selection.

Asymmetric: **helps pit (+0.0121, within-tier +0.0208, t45 +0.0267) but badly hurts hit
(-0.0165, within-tier -0.0486)** -- weighted-Spearman pins alpha at the grid max (300) every
fold for hitters, over-regularizing the ridge toward the FV prior and killing the within-tier
signal. Fails c2 (hit -0.0165 < -0.002), c3 (hit tier), c4 (hit 2022-23 -0.0204).

Grid-vs-criterion diagnostic: pit's gain is **criterion-driven, not grid-driven**
(base-grid+wspearman pit +0.0082; wide-grid+MAE pit -0.0030). The WIDE grid is what poisons
hitters (it lets wspearman reach alpha 300; base-grid+wspearman hit is a near-neutral -0.0006).
Keep-alive: weighted-Spearman selection on the BASE grid (pit +0.0082, hit ~neutral) is a
promising future cell, but carving it out post-hoc would be goalpost-moving -- re-open as its
own pre-registered gate. **No production code changed** (`prospect_path._ALPHAS` unchanged).
