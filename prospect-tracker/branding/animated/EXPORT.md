# Animated mark, export notes

The animated mark is the pixel pitch (owner answer PB-Q4, served on every page
since 2026-10-02): the arc lights run by run, left to right, then the ball drops
onto the apex in whole-pixel steps. It plays once and holds the finished mark;
nothing loops.

The in-site source of truth is CSS: the pixel-wordmark block of
`assets/site.css` (a verbatim copy of `assets/brand/wordmark.css`) running on the
committed fragments `assets/brand/wordmark-s{2,4,6}.svg`. The homepage hero plays
it on load; every wordmark replays it on hover and on keyboard focus. All of it is
generated by `python tools/pixel_brand.py` from `tools/pixel_brand_src.py`.

## The export

`branding/pixel/eephus-arc.gif` is the same timeline as a GIF on the dark field:
exact palette, no dither, no loop key, so it plays once and ends on the still
mark. Use it where a moving mark is wanted outside the site (social, decks,
README embeds).

Static fallback (favicons, anywhere motion does not belong): the wordmark strikes
`branding/pixel/wordmark-s{2,4,6}-{light,dark}.png`, or the marks in
`branding/pixel/marks/`.

The vector draw-on this folder used to hold (`eephus-arc.svg`, its looping
`eephus-arc.gif` and the `frames/` sequence) was retired on 2026-10-02 with the
vector wordmark it animated.
