# eephus.io

Interactive MLB analytics platform: prospect rankings, college baseball leaderboards,
draft tools, and more.

The application lives in [`prospect-tracker/`](prospect-tracker/README.md) - see that
README for setup, the site structure, and how to run the data pipeline. PROSPX
(`prospect-tracker/prospx/`) is the flagship module and the app's design reference;
CollegeSavant and the MLB Draft/HS tools (including an interactive mock draft
simulator and a live draft lottery) are folded into the same shell.
